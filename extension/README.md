# Prompt Improver - Chrome/Edge Extension

This directory contains the React and TypeScript source code for the Chrome/Edge extension.

## Planned Structure
- `src/options/` - Options page
- `src/popup/` - Popup interface
- `src/background/` - Service worker (background scripts)
- `src/content/` - Content scripts for integrating with ChatGPT, Claude, and Gemini web interfaces
- `manifest.json` - Extension manifest (Manifest V3)
